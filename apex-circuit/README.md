# 环线竞速 · APEX CIRCUIT

伪 3D 街机赛车游戏。所有画面与音效都在运行时程序生成：没有图片、没有音频文件、没有第三方库，也没有网络请求。

## 运行

```bash
node server.js        # → http://localhost:5174/
```

`index.html` 使用的是普通 `<script>` 标签，因此直接用浏览器打开也能运行。

## 玩法

3 圈环线，5 位 AI 车手（难度可切换）。沿用真实赛制：**你在最后一位发车**，前方的对手要一个个超。

- 弯道有离心力，会把车推向弯外。入弯前松油或点刹，弯心之后再给油。
- `空格` 是手刹：转向更利、明显掉速，用来修正入弯角度。
- 冲出路面会明显掉速并伴随车身抖动；撞路边物、追尾对手都会损失速度。
- 页面右侧的进度条上，彩色圆点是各对手的位置，橙色是你。

## 操作

| 动作 | 按键 |
| --- | --- |
| 加速 | `↑` / `W` |
| 刹车 | `↓` / `S` |
| 转向 | `←` `→` / `A` `D` |
| 手刹 | `空格` |
| 暂停 / 继续 | `Esc` / `P` |
| 重新开始 | `R` |
| 静音 | `M` |

触屏设备会自动显示虚拟按键。

## 源码结构

| 文件 | 职责 |
| --- | --- |
| `index.html` / `styles.css` | 页面结构、HUD、菜单与结算界面 |
| `js/util.js` | 数学、插值与伪 3D 投影 |
| `js/track.js` | 赛道拼装（直角、弯组、坡道）与路边景物布置 |
| `js/sprites.js` | 程序化贴图：树、岩石、锥桶、广告牌、终点门、赛车 |
| `js/race.js` | 物理、AI 对手、圈速与名次，纯逻辑无 DOM |
| `js/renderer.js` | 伪 3D 渲染：天空、落日、远山视差、雾、速度线、车厢晃动 |
| `js/audio.js` | WebAudio 合成的引擎声、路噪、碰撞与提示音 |
| `js/game.js` | 主循环、输入、HUD 与比赛流程 |

## 数据说明

- 赛道用固定随机种子生成，因此每个人的赛道布局完全一致，圈速可以互相比较。
- 个人最快单圈保存在浏览器 `localStorage`（键 `apex-circuit.best-lap`），只存在本机，不会上传。
- 对手名称（KAI / RYU / NOVA / ZED / MILA）与圈速成绩都是游戏内的模拟数据，不代表真实赛事。
