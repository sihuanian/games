---
name: text-translator
description: 将文本翻译为指定语言并以原文译文对照表格展示。当用户需要翻译文本时使用。
---

# 输入

用户提供以下信息：

- **原文**（必填）：要翻译的文本内容。
- **目标语言**（必填）：翻译的目标语言，如"英语"、"日语"、"法语"等。
- **源语言**（可选）：原文的语言，如"中文"、"英语"等。不指定时自动检测。

> 输入缺失或存在歧义时（如用户只说"翻译一下"未提供原文），必须先通过 AskUserQuestion 向用户澄清，不得使用默认值或推测。

# 输出

以 Markdown 表格展示原文与译文的对照：

| 原文 | 译文 |
|------|------|
| [源语言文本] | [目标语言翻译] |

- 多段落/多句时，按句子或自然段落分行展示。
- 表格上方标注语言方向，如"中文 → 英语"。

# 步骤

1. **解析输入**：提取用户提供的原文、目标语言和源语言（可选）。原文缺失或目标语言不明确时，通过 AskUserQuestion 向用户澄清。
2. **语言检测**：若源语言未指定，根据原文内容自动判断语言。
3. **执行翻译**：将原文逐句/逐段翻译为目标语言。翻译时保持原文的格式、特殊字符和换行结构。
4. **构建对照表**：将原文和译文按行/段对应填入 Markdown 表格，上方标注语言方向。
5. **输出结果**：将对照表格输出给用户。如果原文较长，可在表格后附加说明（如翻译总字数/段落数）。

# 风险与限制

- **上下文长度限制**：极长的文本（超过模型上下文窗口）可能无法一次性翻译完成，需分段处理。
- **专业术语**：对于特定领域的专业术语（如法律、医学、技术），翻译可能不够准确，建议用户补充领域背景。
- **禁止编造数据**：如果工具/API 未返回数据，返回明确提示，不得生成占位内容。

# 错误处理

| 错误场景 | 处理策略 | 用户提示 |
|---------|---------|---------|
| 未提供原文 | AskUserQuestion 澄清 | 请提供要翻译的文本内容 |
| 未指定目标语言 | AskUserQuestion 澄清 | 请问要翻译成哪种语言？ |
| 原文为空 | 返回错误提示 | 原文为空，请提供需要翻译的文本 |
| 语言不支持 | 返回错误提示 | 暂不支持该语言，请尝试其他目标语言 |

# 示例

**示例 1：中译英**

输入：
> 原文：今天天气很好，适合出去散步。
> 目标语言：英语

输出：
| 原文 | 译文 |
|------|------|
| 今天天气很好，适合出去散步。 | The weather is great today, perfect for a walk outside. |

**示例 2：日译中（自动检测源语言）**

输入：
> 原文：昨日はとても楽しかったです。
> 目标语言：中文

输出：
| 原文 | 译文 |
|------|------|
| 昨日はとても楽しかったです。 | 昨天非常开心。 |
