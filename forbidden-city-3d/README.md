# 紫禁城中轴线 · 三维重建沙盘

以程序化重建方式呈现紫禁城中轴线自午门至神武门的三维空间格局、建筑形制与屋面关系。所有几何与贴图都在运行时生成：没有外部图片、没有第三方脚本，也没有网络请求。

## 运行

```bash
node server.js        # → http://localhost:5173/
```

页面使用 ES Module 与 importmap，需通过 HTTP 访问；直接双击 `index.html` 会被浏览器的模块跨域策略拦下。

## 观察方式

| 方式 | 说明 |
| --- | --- |
| 材质效果 | 默认。琉璃瓦、朱墙、汉白玉与金饰材质，带日照与阴影 |
| 白模 | 单色石膏体量，用来看体块与轮廓关系 |
| 线框 | 按屋面／屋身／台基分色的线框，用来看结构分层 |
| 形制图谱 | 按屋顶形制分类着色，并显示右下角的形制图例 |

## 操作

- 左侧「轴线序列」：自午门至神武门的十二站，另含全景与角楼特写，点击即移动相机。
- 右侧面板：当前站点的形制、尺寸与功能说明。
- 底部「展示控制」：切换观察方式与图层（两翼院落／宫墙角楼／水系／植被／形制标注）、拖动日照时刻滑块、轴线巡游与重置视角。
- 三维视图内可直接旋转、平移、缩放。

## 源码结构

| 文件 | 职责 |
| --- | --- |
| `index.html` / `src/css/app.css` | 页面骨架、importmap、HUD 与视觉系统 |
| `src/js/main.js` | 入口：WebGL 检测、场景组装、渲染循环、事件接线 |
| `src/js/geometry.js` | 古建几何引擎：举折、翼角起翘、正脊／垂脊／戗脊、斗拱、须弥座 |
| `src/js/buildings.js` | 单体装配：殿宇、城台门、角楼、城墙、廊庑、亭、桥 |
| `src/js/city.js` | 中轴线总平面、视角预设与站点注册 |
| `src/js/materials.js` | 材质库与四种观察方式的材质切换 |
| `src/js/textures.js` | 程序化贴图（canvas 实时生成，无外部图片） |
| `src/js/sky.js` | 由「时刻」驱动的日照角度、天空贴图与环境光 |
| `src/js/labels.js` | 三维标注层（世界坐标投影到屏幕，带简单避让） |
| `src/js/ui.js` | 界面层：轴线导航、详情、图例、提示 |
| `src/js/data.js` | 各站的事实数据 |
| `vendor/three/` | 离线内置的 Three.js（免安装、免网络） |
| `server.js` | 极简静态服务器 |

## 数据说明

- 形制与尺寸以**故宫博物院官网（dpm.org.cn）各建筑条目正文**为主要依据。
- 官网未载、仅见于通行资料的说法已单独标注：午门通高约 37.95 m、内金水桥的「汉白玉」及御路桥／王公桥／品级桥桥名。这些内容在界面上会显示「待核」提示，未当作定论。
- 各殿「面阔／进深」的米制数值官网亦未列出，故面板采用官网的「间」数；三维模型按通行资料的数值取整建模。
- 三维模型为程序化重建，平面与高度按接近真实的米制尺度布置，但建筑体量经过简化，**非测绘数据**，不作测量或复原依据。
