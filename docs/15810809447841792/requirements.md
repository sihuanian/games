# 坦克大战 需求文档

- 文档版本 / 基线状态：v0.1（需求基线初稿）
- 目标设备：桌面 Web

## 1. 项目背景与目标

### 背景

坦克大战（Battle City）是经典的俯视角射击游戏。用户希望开发一款可运行的坦克大战游戏。

### 目标

玩家操控己方坦克，在关卡场景中移动并射击，击毁不断出现的敌方坦克；同时保护己方基地不被敌方坦克或子弹摧毁。

### 成功结果

- 玩家能进入游戏并开始对局。
- 玩家能操控坦克四方向移动并射击，操作即时响应。
- 能正确判定子弹命中、摧毁与得分。
- 能正确判定胜利（击毁全部敌方坦克）与失败（基地被毁或生命耗尽）。
- 游戏在桌面 Web 浏览器中流畅运行。

### 基线状态说明

本文档为需求基线初稿。用户只提出了「开发坦克大战」这一目标；未明确指定具体规则、范围或优先级。下文为完成经典坦克大战核心玩法所必需的规则，均以「推荐基线」明确标注，可在后续迭代中确认或调整，不将其视为用户已确认的正式决定。

## 2. 用户旅程与关键场景

### 场景 C-01：开始游戏

- 进入游戏后看到开始入口。
- 玩家触发开始。
- 关卡初始化，显示玩家坦克、基地、场地与首波敌方坦克。
- 对局进入进行中状态。

### 场景 C-02：操控与战斗

- 玩家通过方向输入移动坦克、通过射击输入发射子弹。
- 子弹飞行并与目标发生碰撞判定。
- 命中的目标（砖墙、敌方坦克）被摧毁或受损，得分实时更新。

### 场景 C-03：保护基地

- 敌方坦克向基地逼近或射击。
- 基地被有效命中后即被摧毁。
- 对局立即进入失败状态。

### 场景 C-04：生命耗尽

- 玩家坦克被敌方子弹命中，损失一条生命。
- 生命归零后对局进入失败状态。

### 场景 C-05：通关

- 玩家击毁本关全部敌方坦克。
- 显示通关结果，可进入下一关。

## 3. 状态模型与业务规则

### 对局状态（推荐基线）

- 未开始（initial）：进入游戏后、开始前的状态。
- 进行中（playing）：对局进行，玩家可操作。
- 胜利（won）：本关全部敌方坦克被击毁。
- 失败（lost）：己方基地被摧毁，或玩家生命耗尽。

> 推荐基线：可额外提供「暂停（paused）」状态，供玩家临时暂停对局；非必需项。

### 业务规则（推荐基线）

- 玩家坦克初始生命为 3 条。
- 敌方坦克按批次出现，需击毁本关全部敌方坦克才能通关。
- 基地只能承受一次有效命中，被命中即被摧毁。
- 砖墙可被子弹摧毁；钢墙不可被普通子弹摧毁。
- 击毁敌方坦克获得分数（不同敌方等级对应不同分数，具体数值由实现阶段确定）。

## 4. 分模块功能需求

### 模块 1：游戏开始与关卡

- 进入游戏后显示开始入口，玩家可开始对局。
- 开始后初始化关卡：生成玩家坦克、基地、场地与首波敌方坦克。
- 对局中持续显示当前得分、剩余生命与剩余敌方坦克数量。

### 模块 2：玩家坦克操作

- 支持上、下、左、右四个方向移动。
- 支持朝当前朝向发射子弹。
- 移动与射击应即时响应。
- 坦克不得移出场地边界，不得穿越不可破坏的障碍（推荐基线）。

### 模块 3：敌方坦克行为

- 敌方坦克自动生成，并自主移动、射击（推荐基线）。
- 敌方坦克可向基地和玩家方向运动并开火（推荐基线）。
- 本关全部敌方坦克被击毁后判定胜利。

### 模块 4：地形与碰撞

- 砖墙：可被子弹摧毁（推荐基线）。
- 钢墙：不可被普通子弹摧毁（推荐基线）。
- 基地：被敌方子弹或敌方坦克命中即被摧毁（推荐基线）。

### 模块 5：战斗判定

- 子弹命中敌方坦克：敌方坦克被摧毁，得分增加。
- 敌方子弹命中玩家坦克：玩家损失一条生命（推荐基线）。
- 己方子弹与敌方子弹相遇可相互抵消（推荐基线，非必需）。

### 模块 6：得分、生命与结果

- 实时显示得分与剩余生命。
- 胜利条件：击毁本关全部敌方坦克。
- 失败条件：基地被摧毁，或玩家生命耗尽。
- 对局结束后显示对应结果。

## 5. 非功能要求

- 游戏在桌面 Web 浏览器中可运行，移动与射击操作即时响应，无肉眼可见的明显卡顿影响可玩性。
- 核心玩法遵循经典坦克大战规则，玩家无需额外说明即可上手。

## 7. 验收场景

### AC-01：进入游戏并可开始对局
- 验收条件：进入游戏后显示开始入口，触发开始后可进入对局。
- 入口类型：用户界面
- 前置条件：游戏页面可访问。
- 触发动作：打开游戏并触发开始。
- 预期结果：关卡初始化完成，显示玩家坦克、基地与场地，对局进入进行中状态。
- 证据类型：runtime-render

### AC-02：玩家坦克四方向移动
- 验收条件：玩家可通过方向输入控制坦克在上、下、左、右四个方向移动。
- 入口类型：用户界面
- 前置条件：对局处于进行中状态。
- 触发动作：分别触发上、下、左、右移动输入。
- 预期结果：坦克按输入方向移动，且不越过场地边界或穿越不可破坏障碍。
- 证据类型：interaction

### AC-03：玩家坦克射击发射子弹
- 验收条件：玩家可通过射击输入朝当前朝向发射子弹。
- 入口类型：用户界面
- 前置条件：对局处于进行中状态。
- 触发动作：触发射击输入。
- 预期结果：子弹沿坦克当前朝向发射并向前飞行。
- 证据类型：interaction

### AC-04：子弹摧毁砖墙
- 验收条件：子弹命中砖墙后，砖墙被摧毁。
- 入口类型：用户界面
- 前置条件：对局处于进行中状态，且场景中存在砖墙。
- 触发动作：朝砖墙方向射击。
- 预期结果：子弹命中砖墙后砖墙被摧毁。
- 证据类型：interaction

### AC-05：子弹命中并摧毁敌方坦克，得分增加
- 验收条件：子弹命中敌方坦克后，敌方坦克被摧毁，得分增加。
- 入口类型：用户界面
- 前置条件：对局处于进行中状态，且场景中存在敌方坦克。
- 触发动作：朝敌方坦克方向射击并命中。
- 预期结果：敌方坦克被摧毁，界面得分相应增加。
- 证据类型：interaction

### AC-06：敌方坦克自主生成、移动与射击
- 验收条件：对局中敌方坦克自动生成，并自主移动与射击。
- 入口类型：用户界面
- 前置条件：对局处于进行中状态。
- 触发动作：开始对局并观察敌方坦克行为。
- 预期结果：敌方坦克自主出现并移动、射击，无需玩家输入。
- 证据类型：runtime-render

### AC-07：基地被毁导致对局失败
- 验收条件：基地被敌方命中摧毁后，对局立即失败。
- 入口类型：用户界面
- 前置条件：对局处于进行中状态。
- 触发动作：使基地被敌方子弹或敌方坦克命中。
- 预期结果：基地被摧毁，对局进入失败状态并显示失败结果。
- 证据类型：interaction

### AC-08：玩家生命耗尽导致对局失败
- 验收条件：玩家生命归零后，对局失败。
- 入口类型：用户界面
- 前置条件：对局处于进行中状态。
- 触发动作：使玩家坦克被敌方子弹多次命中直至生命归零。
- 预期结果：玩家生命耗尽，对局进入失败状态并显示失败结果。
- 证据类型：interaction

### AC-09：击毁全部敌方坦克获得胜利
- 验收条件：击毁本关全部敌方坦克后，对局胜利。
- 入口类型：用户界面
- 前置条件：对局处于进行中状态。
- 触发动作：击毁本关出现的全部敌方坦克。
- 预期结果：对局进入胜利状态并显示通关结果，可进入下一关。
- 证据类型：interaction

### AC-10：界面显示得分、生命与剩余敌人信息
- 验收条件：对局界面实时显示当前得分、剩余生命与剩余敌方坦克数量。
- 入口类型：用户界面
- 前置条件：对局处于进行中状态。
- 触发动作：观察对局界面信息。
- 预期结果：界面显示得分、剩余生命与剩余敌方坦克数量，并随对局进展更新。
- 证据类型：runtime-render
